关于本次预览
这些页面是 M1 MVP 的视觉稿，仅展示客户端样式与交互。完整功能包括意图解析、浏览器抓取、双通道写入由 FastAPI 后端提供（详见 raw/datapilot/）。 当前为 Mock 模式：写入飞书文档与 MySQL 的操作实际落到本地 JSON 文件，便于演示与审计。
